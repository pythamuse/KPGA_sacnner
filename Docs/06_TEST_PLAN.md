# TEST_PLAN — 테스트 계획

## 1. 테스트 범위

테스트는 다음 5개 영역으로 나눈다.

1. 데이터 정규화 테스트
2. 데이터 검증 테스트
3. 엑셀 쓰기 테스트
4. 이미지 인식 결과 처리 테스트
5. 통합 다운로드 테스트

---

## 2. 데이터 정규화 테스트

### 2.1 성별 정규화

| 입력 | 기대값 |
|---|---|
| 남 | 남 |
| 남자 | 남 |
| 남학생 | 남 |
| 여 | 여 |
| 여자 | 여 |
| 여학생 | 여 |

실패 케이스:

| 입력 | 기대 결과 |
|---|---|
| 기타 | 오류 |
| 공백 | 오류 |
| null | 오류 |

### 2.2 학교유형 정규화

| 입력 | 기대값 |
|---|---|
| 초등 | 초등학교 |
| 초등학교 | 초등학교 |
| 중등 | 중학교 |
| 중학교 | 중학교 |
| 고등 | 고등학교 |
| 고등학교 | 고등학교 |
| 학교 외 기관 | 학교외기관 |
| 학교외기관 | 학교외기관 |

### 2.3 학년 정규화

| 입력 | 기대값 |
|---|---|
| 1 | 1학년 |

| 해당없음 | 해당없음 |

## 3. 검증 테스트

### 3.1 기본정보

| age=0 | 실패 |
| age=21 | 실패 |
| gender=여 | 통과 |

### 3.3 만족도

## 4. 엑셀 쓰기 테스트

### 4.1 단일 학생 저장

입력:

```json
{
  "basic": { "age": 14, "gender": "여", "schoolType": "중학교", "grade": "2학년" },
  "cagi": { "q01": 0, "q02": 0, "q03": 0, "q04": 0, "q05": 0, "q06": 0, "q07": 0, "q08": 0, "q09": 0 },
  "satisfaction": { "q01": 4, "q02": 1, "q03": 1, "q04": 1, "q05": 1, "q06": 1, "q07": 4, "q08": 4, "q09": 4, "q10": 4 }
}
```

기대 결과:

CAGI:

```text
A3=14, B3=여, C3=중학교, D3=2학년, E3:M3=0
```

만족도:

```text
A3=14, B3=여, C3=중학교, D3=2학년, E3:N3=4,1,1,1,1,1,4,4,4,4
```

### 4.2 다중 학생 저장

학생 10명을 저장하면 다음을 검증한다.

| 검증 | 기대 결과 |
|---|---|
| CAGI 입력 행 | 3~12행 |
| 만족도 입력 행 | 3~12행 |
| 두 파일 행 수 | 동일 |
| 13행 | 비어 있음 |

### 4.3 실패 트랜잭션

케이스:

- CAGI는 정상
- 만족도 q02=4로 오류

기대 결과:

- CAGI 파일에도 저장하지 않음
- 만족도 파일에도 저장하지 않음
- 사용자에게 오류 메시지 표시

## 5. 템플릿 보존 테스트

저장 후 다음을 확인한다.

| 항목 | 기대 결과 |
|---|---|
| 시트명 | 유지 |
| 코드 시트 | 유지 |
| 1행 제목 | 유지 |
| 2행 예시 | 유지 |
| 병합셀 | 유지 |
| 스타일 | 유지 |
| 데이터 유효성 검사 | 유지 |
| x14:dataValidations | 가능하면 유지 |

엑셀에서 직접 열었을 때 드롭다운이 사라지면 실패이다.

## 6. 이미지 인식 테스트

### 6.1 예시 이미지 고정 테스트

입력 이미지:

1. 선별검사지 예시 이미지
2. 만족도 예시 이미지

기대값:

```json
{
  "basic": { "age": 14, "gender": "여", "schoolType": "중학교", "grade": "2학년" },
  "cagi": [0,0,0,0,0,0,0,0,0],
  "satisfaction": [4,1,1,1,1,1,4,4,4,4]
}
```

### 6.2 이미지 뒤바뀜 테스트

| 업로드 위치 | 이미지 | 기대 결과 |
|---|---|---|
| CAGI 칸 | 만족도 이미지 | 양식 불일치 오류 |
| 만족도 칸 | CAGI 이미지 | 양식 불일치 오류 |

### 6.3 품질 저하 테스트

| 상황 | 기대 결과 |
|---|---|
| 흐림 | 낮은 신뢰도 또는 재촬영 요청 |
| 종이 일부 잘림 | 재촬영 요청 |
| 심한 그림자 | 재촬영 요청 |
| 기울어짐 | 보정 시도, 실패 시 재촬영 요청 |

---

## 7. 사용자 수정 테스트

| 케이스 | 기대 결과 |
|---|---|
| OCR이 성별을 남으로 인식했으나 사용자가 여로 수정 | 엑셀에는 여 저장 |
| OCR이 문항1을 3으로 인식했으나 사용자가 4로 수정 | 엑셀에는 4 저장 |
| 사용자가 허용값 밖의 값 입력 시도 | 입력 차단 |

사용자 확정값은 OCR 원본값보다 우선한다.

---

## 8. 완료 및 다운로드 테스트

| 조건 | 기대 결과 |
|---|---|
| 모든 학생 confirmed | 다운로드 가능 |
| 오류 학생 존재 | 다운로드 제한 |
| 학생 0명 | 다운로드 제한 또는 빈 양식 다운로드 여부를 정책적으로 선택 |
| 파일 생성 실패 | 오류 메시지 표시 |

- [ ] 오류 메시지를 보고 사용자가 무엇을 해야 하는지 알 수 있는가?
