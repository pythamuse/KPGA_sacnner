# ACCEPTANCE_CHECKLIST — 최종 인수 체크리스트

## 1. 핵심 기능

- [x] 새 작업을 생성할 수 있다.
- [x] 선별검사지 이미지를 업로드할 수 있다.
- [x] 만족도 이미지를 업로드할 수 있다.
- [x] 이미지가 서로 뒤바뀌면 감지한다. (`FORM_TYPE_MISMATCH`)
- [x] OCR/Form Recognition 결과가 확인 화면에 표시된다.
- [x] 사용자가 인식값을 수정할 수 있다.
- [x] 검증 실패 시 저장되지 않는다.
- [x] 검증 통과 시 두 엑셀 파일에 같은 행 번호로 저장된다.
- [x] 완료 후 CAGI 파일과 만족도 파일을 다운로드할 수 있다.

비고:

- 위 항목은 현재 자동 테스트 기준으로 확인된 기능이다.
- 카메라 촬영 흐름은 구현되어 있으나 모바일 HTTPS 실기기 수동 검증이 별도로 필요하다.
- OCR/Form Recognition은 MVP 상태이며 실제 촬영 이미지 정확도 검증은 아직 남아 있다.

---

## 2. 데이터 정확성

- [ ] 선별검사지에서 연령대가 추출된다.
- [x] 선별검사지에서 성별이 추출된다. (CAGI ROI MVP)
- [ ] 성별은 남/여로 저장된다.
- [ ] 선별검사지에서 학교유형이 추출된다.
- [ ] 선별검사지에서 학년이 추출된다.
- [x] CAGI 01~09가 추출된다. (ROI MVP, 실제 촬영 샘플 추가 검증 필요)
- [x] 만족도 문항1~10이 추출된다. (ROI MVP, 실제 촬영 샘플 추가 검증 필요)
- [ ] 만족도 A~D열은 선별검사지 기본정보를 복사한다.
- [x] 만족도 이미지에서 기본정보를 추출하지 않는다.

## 4. 엑셀 결과

### CAGI 파일

- [ ] 3행부터 입력된다.
- [ ] A3=14
- [ ] B3=여
- [ ] C3=중학교
- [ ] D3=2학년
- [ ] E3:M3=0

### 만족도 파일

- [ ] 3행부터 입력된다.
- [ ] A3=14
- [ ] B3=여
- [ ] C3=중학교
- [ ] D3=2학년
- [ ] E3:N3=4,1,1,1,1,1,4,4,4,4

---

## 5. 검증 실패 케이스

- [x] 만족도 문항1=0이면 저장 실패한다.
- [x] 만족도 문항2=4이면 저장 실패한다.
- [x] CAGI 문항=4이면 저장 실패한다.
- [x] 성별=남자 상태로 저장하려 하면 실패하거나 남으로 정규화된다.
- [x] 학교유형이 허용값 밖이면 실패한다.
- [ ] 선별검사지 이미지만 있고 만족도 이미지가 없으면 저장 실패한다.
- [ ] 만족도 이미지만 있고 선별검사지 이미지가 없으면 저장 실패한다.
- [x] 선별검사지 칸에 만족도 이미지가 있으면 `FORM_TYPE_MISMATCH`로 실패한다.
- [ ] 만족도 칸에 선별검사지 이미지가 있으면 `FORM_TYPE_MISMATCH`로 실패한다.
