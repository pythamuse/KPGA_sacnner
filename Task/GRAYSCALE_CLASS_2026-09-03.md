# 회색조 스캔 계급 — 계측과 설계 라운드 (2026-09-03)

감사 §D 6순위(B-5·B-8)와 Docs/17 §3.8. 사용자 결정(주간 사용량 65% 미만 → 착수, 같은 기기 회색조 재스캔 없이 세트 4를
판정 표본으로). §2대로 계측이 먼저다.

## 1. 계측 — 같은 19명, 세트 1(1비트) 대 세트 4(회색조 600dpi·다른 기기), 후보 1,558쌍

`tests/_probe-tracedump.test.ts`로 두 세트의 결정 트레이스를 뽑아 (쪽, 필드, 후보 위치)로 짝지었다. "표시 칸"은 세트 1이
정답을 낸 그룹의 승자, "무표시 칸"은 같은 그룹의 나머지.

| | 무표시 칸 (n=992) | 표시 칸 (n=359) |
|---|---|---|
| `page/blank` 중앙값, 세트 1 | 0.727 | 1.327 |
| `page/blank` 중앙값, 세트 4 | **0.305** | 0.760 |
| 세트 4 / 세트 1 페이지 잉크 비(p10/p50/p90) | 0.26 / **0.42** / 0.88 | 0.37 / **0.55** / 0.85 |
| 점수 ≥ floor(0.021) | 227 → 32 | **358 → 222** |
| 페이지 선명도(sharp) 중앙값 | 0.128 → 0.063 (빈 양식 0.181) | 0.242 → 0.139 |

**결론**: 세트 4에서는 **인쇄 구조 자체가 빈 양식 자산의 0.41~0.57배**(페이지별 중앙값 `r_page`, 기기 상수에 가까움)로
옅다. 차분 `page − blank − 0.08`이 인쇄 구조 차이를 표시 잉크에서 빼 버려 표시 칸 132칸이 floor를 못 넘는다. 이것이
§17.2 "점수 전 학생 ½"의 실체이며, §32.7의 빈 양식 교체 실패와 모순되지 않는다 — 자산을 바꾸는 대신 **자산의 darkness를
페이지의 인쇄 구조 비율로 스케일**해야 한다.

집계 근사(상자 평균) 시뮬레이션 — 방향만:

| 변형 | 표시 칸 양성 /359 | 무표시 양성 /992 |
|---|---|---|
| 현재 | 5 | 3 |
| `blank × r_page/0.73`, 마진 0.08 | 16 | 4 |
| `blank × r_page/0.73`, 마진 0.08×r | 89 | 19 |
| 세트 1 참조(현재 규칙) | 53 | 0 |

마진을 그대로 두면 회복이 적고, 비율로 줄이면 무표시 양성이 는다 → 마진은 **페이지의 무표시 잡음에서 유도**해야 한다.

## 2. 주문 (`gray-order.md`, 브랜치 `codex-gray-class`, 플래그 `GRAY_CLASS`)

- 계급 `grayscale-scan` = `pageIsBinarySource=false && !photoProvenance`. 1비트·사진은 바이트 동일.
- `gain = clamp(r_page / 0.73, 0.3, 1.0)`, 잔차 = `max(0, page − blank×gain − margin)`, 마진은 페이지 후보 상자의
  `(page − blank×gain)` 중앙값 + 2×MAD를 `[0.03, 0.08]`로 묶음. 게이트 문턱은 불변.
- B-8: 기준선↔페이지 후보 중심 거리 계측만(`[baseline-pair]`), 동작 변경 없음.
- 판정: 스캔 1~3·사진 바이트 동일, 세트 4 정답↑·오답 비증가·빈칸이어야 하는 칸 유지.

## 3. B-8 짝짓기 계측 결과 (`[baseline-pair]`, 코덱스 `f9d8bbc`의 계측기)

기준선 후보 사각형과 페이지 후보 사각형의 정규화 중심 거리 `maxDev`(ok = ≤ 0.5×최소 간격):

| 세트 | n | maxDev p50 / p90 / max | ok=0 |
|---|---|---|---|
| 스캔 1 | 418 | 0.0033 / 0.0074 / 0.0157 | **0** |
| 스캔 4(회색조) | 418 | 0.0037 / 0.0073 / 0.157 | 10 — **전부 `basic.*`** |
| 사진 OLD | 418 | 0.0050 / 0.0142 / 0.157 | 19 — **전부 `basic.*`** |

선택지 표(`cagi.*`·`satisfaction.*`)에서는 세 세트 모두 색인 짝짓기가 기하적으로도 맞는다(최대 편차 0.016, 간격의 1/5).
`ok=0`은 전부 `basic.*`이고 값이 페이지마다 같다(0.0773 / 0.1573 / 0.0956) — 기본정보 상자는 자체 정합 경로
(`basicCheckboxDetection`)를 쓰고 실패 시 `fixed/failed`로 자동값을 막으므로(검증 기록 §3.8) 이 계측의 대상이 아니다.
**B-8은 선택지 표에서 실현되지 않았다.** 거절 규칙은 넣지 않고 계측기만 남긴다(다른 기기·양식에서 다시 잰다).

## 4. 1차 측정 — 기각, 원인 둘 (코덱스 `f9d8bbc`, `GRAY_CLASS=1`)

| 조건 | 기준선(V2) | 1차 on | 칸 단위 |
|---|---|---|---|
| 스캔 1 | 361 / 5 | **363 / 7** | 1비트인데 값이 바뀜: blank→correct 4, **blank→wrong 2**(p3 sat.q07, p15 sat.q04) |
| 스캔 2 | 346 / 8 | 350 / 9 | blank→wrong 1(p6 cagi.q07) |
| 스캔 4 | 232 / 11 | **318 / 13** | blank→correct **88**, blank→wrong 3(p5·p11 sat.q04, p18 cagi.q04), wrong→blank 1 |

1. **계급 게이트 오판**: `pageIsBinarySource`는 업로드 JPEG(q0.86) 뒤에는 1비트 스캔에서도 거짓이 된다(중간 화소 > 1%).
   그래서 세트 1·2가 회색조로 분류돼 유도 마진이 적용됐다. → 게이트를 **페이지의 인쇄 구조 비율** `r_page < 0.62`로
   바꿨다(세트 1 ≈ 0.73, 회색조 기기 0.41~0.57). 1비트는 구조적으로 바이트 동일.
2. **유도 마진(중앙값 + 2·MAD)이 오답을 만든다**: 세트 4 +2, 세트 1 +2. gain은 세트 1에서 ≈1.0이므로 세트 1의 변화는
   전부 마진 탓이다. → 마진 규칙을 측정 스위치 `GRAY_MARGIN=fixed|scaled|derived`로 두고 세트 4에서 셋을 잰다.

세트 4의 정답 +88은 계측이 예측한 방향 그대로다(1차에서 이미 232→318). 판정은 "오답 비증가"를 만족하는 마진 규칙이
있는지에 달렸다.

## 5. 2차 측정 — 게이트 수정 후 마진 규칙 비교 (`766af97`)

계급 게이트를 `r_page < 0.62`로 바꾸자 **세트 1은 플래그를 켜도 바이트 동일**(361/5, 칸 변화 0), 사진 OLD도 동일(61/0).
세트 4에서 마진 규칙 셋:

| 규칙 | 세트 4 | 기준선(232/11) 대비 | 판정 |
|---|---|---|---|
| `fixed` (0.08 유지) | 290 / **12** | 정답 +58, 오답 +1(p18 cagi.q04) | 기각(오답 증가) |
| **`scaled` (0.08 × gain)** | **307 / 11** | 정답 +75, 오답 동일(1 소멸·1 신규) | **채택** |
| `derived` (중앙값 + 2·MAD) | 317 / **13** | 정답 +85, 오답 +2 | 기각 |

`scaled`를 기본값으로, 계급을 기본 ON으로 바꿨다(`5cf5429`; `GRAY_CLASS=0`이 이전 동작). §1의 집계 근사가 "마진을
비율로 줄이면 무표시 양성이 는다"고 경고했던 것은 4중 게이트가 걸러 실제 오답으로는 이어지지 않았고, 반대로
"유도 마진"이 실제로는 오답을 만들었다 — 집계 근사는 방향만 믿는다는 §1의 단서가 맞았다.

p18 `cagi.q04 = 0`(정답 1)은 세 규칙 모두에서 생긴다 — 표시 잉크가 옅은 회색조 특유의 칸으로, 다음 표적.

메인 시험 466/0(기본값·`GRAY_CLASS=0` 모두). 브라우저 재대조는 하지 않았다 — 세트 1~3은 구조적으로 바이트 동일이라

들어올 때 한다).

**닫히는 것**: B-5의 값 생산 상수(`darkness()` 178, 마진 0.08)가 이제 **입력 계급별로** 작동한다 — 1비트는 그대로, 회색조는
페이지의 인쇄 구조 비율로 기준선을 맞춘다. §5.5의 "회색조 스캔은 회귀다(355→223)"는 "계급 보정 후 307/11"로 갱신.
**남는 것**: 세트 4 잔여 오답 11(그중 p18 cagi.q04는 이 보정이 만든 유일한 신규)과 빈칸 119 — 다음 표적은 회색조에서
옅은 표시 잉크의 floor(0.021)이며, 이것은 게이트 완화가 아니라 잉크 신호 측정(획 두께 대신 면적)으로 풀어야 한다.
새 세트 4 기준선: **307 / 11 / 119 · OFF 70**.
