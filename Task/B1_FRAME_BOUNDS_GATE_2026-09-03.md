# B-1 — 대체 경계(frame/legacy)는 자동값을 만들지 못한다 (2026-09-03)

감사 §D 3순위. 소견 B-1([Docs/16](../Docs/16_RECOGNITION_DESIGN_AUDIT.md))과 검증 기록
[§3.1](DESIGN_AUDIT_VERIFICATION_2026-09-03.md). 검증 기록이 "발화 빈도 미확인"으로 남긴 것을 **먼저 계측**하고,
그 결과가 수정을 정당화했으므로 수정했다. 코드 변경은 게이트 두 줄 + 시험이라 위임 왕복보다 측정이 길어
직접 했다(CLAUDE.md §5 "위임 왕복이 측정보다 오래 걸리는 종류").

## 1. 계측 — 게이트가 어떤 경계로 도달하는가

`MARK_BOUNDS_TRACE=1`로 `detectCheckmarks.ts`의 게이트 직전에 시트별 `contentBoundsSource`·판정 사유를
기록하는 계측기(`traceBoundsGate`)와 프로브 `tests/_probe-bounds-gate.test.ts`(커밋 `c5edece`).
제품 인식기를 그대로 돌리며, 스캔 4세트·사진 4세트 = 304시트.

| 세트 | 시트 | `template`(정상) | `frame` → `ok-legacy` 통과 | `dark` 거절 |
|---|---|---|---|---|
| 스캔 1·2·3·4 | 152 | **152** | 0 | 0 |
| 사진 OLD | 38 | 38 | 0 | 0 |
| 사진 Set1 | 38 | 38 | 0 | 0 |
| **사진 Set2(햇볕)** | 38 | 24 | **13** (CAGI 5 · 만족도 8) | 1 |
| 사진 Set3 | 38 | 38 | 0 | 0 |

대체 경로는 **햇볕 세트에서만** 발화했고, 그중 자동값을 만든 시트는 둘(p1 CAGI 5칸, p3 CAGI 1칸)이다.
정답표와 대조(`_probe-photo-trace`):

| 시트 | 대체 경로로 만든 자동값 | 판정 |
|---|---|---|
| Set2 p1 CAGI | q01·q03·q04·q06·q07 = 0 | 5칸 정답 |
| Set2 p3 CAGI | **q01 = 3** (정답 0) | **오답 — 세트 2의 유일한 오답** |

즉 검증 기록이 "결합 경로"로 추정한 오답이 실물로 잡혔다: `pageBounds` 없음 → `frame` → 등록 중단 →
`ok-legacy` 통과 → 프레임 원점으로 밀린 기대 좌표 → 헤더 텍스트가 빽빽한 4열이 잔차를 이겨 "3".
CAPTURE_GUIDANCE §17.1이 남긴 "반쯤 그늘진 p3"이 바로 이 경로였다.

## 2. 수정

`markDensity.ts resolveFormBoundsStatus`: 엄격 모드(기본, 자동값 게이트)에서
- `contentBoundsSource === 'frame'` → `usable: false, reason: 'frame-bounds-only'`
- `pageBounds` 없는 legacy 가장자리 검사 통과 → `usable: false, reason: 'legacy-edges-unverified'`

비엄격 모드(`hasReviewableFormBounds`)는 이전 동작을 유지하며 **조기개입 개인정보 경고**(`cagiEarlyIntervention.ts`)만
쓴다 — 값이 아니라 "종이가 있는가"를 묻는 검수용 신호라서다. `tableRowDetection`의 두 호출은 엄격 게이트를 그대로
따른다(측정에 포함됨). 시험: `recognition-mark-density.test.ts`에 `'frame'`·`pageBounds` 없음 → false 고정.

## 4. 닫히는 것과 남는 것

- B-1 닫힘. 검증 기록 §3.1의 "상시 경로가 아니라 대체 경로의 구멍"이 수치로 확인됐다(스캔 0/152).
- B-3/B-9(열 허용치)의 **운반체 중 하나**가 잘렸다 — 프레임 원점 이동은 이제 값을 만들지 못한다. 그러나
  `pageBounds`가 있는 상태에서 선 검출이 한 열 밀리는 경우(B-3 본체)는 남아 있다. §D 5순위 그대로.
- Set2의 프레임 시트 13장은 이제 자동값 0으로 검수자에게 간다. 그 장들은 재촬영 대상(햇볕·그늘)이며
  M5 가이드가 걸러야 할 표본이다.
