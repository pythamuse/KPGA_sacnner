# 채점기 잡음 바닥 계측 라운드 — 두 다이얼 모두 기각 (2026-09-03)

**표적**: 표시 판정 단계의 거절([FIELD_TEST](FIELD_TEST_2026-08-21.md) §34.7). 브라우저 래스터 19장·정답표 359행에서 표시 칸 점수 p10 0.030이
표시 없는 칸 p90 0.035와 겹친다. 게이트에 걸리는 행 48 중 ≈20행은 틀린 칸이 더 높고(거절이 옳음), 28행이 회복 가능 풀. 가설: 인쇄 글리프의
1px 정렬 잔차가 잡음 바닥을 만든다.
**작성**: 오퍼스 서브에이전트, 브랜치 `scorer-noise`, 커밋 `e81b216`(기준 `ffa87fd`). 기본 off 바이트 동일(합성 240 측정값 md5 동일).
**판정 도구**: `tests/_probe-scorer-cells.test.ts`(후보별 점수 JSONL) + `scorer-separation.py`(정답표와 결합해 점수 게이트만으로 자동 정답/자동 오답/거절을
셈 — 변형 없음에서 브라우저의 오답 9칸을 그대로 재현했다).

글리프 잔차를 다른 축으로 가르는 특징(성분 크기·형태는 p5에서 분리되지 않았다).
